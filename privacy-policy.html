Privacy Policy for Canvas Grading Queue

Effective date: March 19, 2026

Canvas Grading Queue ("the extension") is a teacher productivity tool designed to help instructors using Canvas LMS identify assignments that require grading and quickly open the relevant grading pages.

Information the Extension Accesses

The extension may access limited information from the user's Canvas LMS instance, including:

  • Course names and course identifiers
  • Assignment names and assignment identifiers
  • Assignment grading status, including whether submissions need grading
  • Links needed to open relevant Canvas grading pages

The extension also stores user preferences locally in the browser, such as:

  • Course priorities
  • Filters
  • Snoozed assignments
  • Daily grading targets
  • Other extension settings needed for core functionality

How Information Is Used

The information accessed by the extension is used only to provide the extension's core functionality, including:

  • Displaying a centralized grading queue
  • Helping instructors prioritize assignments that need grading
  • Opening the correct Canvas grading pages
  • Saving local teacher preferences for a better workflow

Data Storage

Canvas Grading Queue stores settings and workflow preferences locally using the browser's extension storage.

The extension does not send this information to any developer-operated server or third-party analytics service.

Data Sharing

Canvas Grading Queue does not sell, rent, or share user data with third parties.

The extension communicates only with the user's Canvas LMS instance as needed to retrieve data required for its functionality.

Remote Code

Canvas Grading Queue does not use remote code.

Children's Privacy

This extension is intended for use by instructors and teachers. It is not directed to children.

Security

The extension is designed to minimize permissions and only requests access necessary to support its single purpose as a grading workflow tool for Canvas LMS instructors.

Changes to This Privacy Policy

This privacy policy may be updated from time to time. Any updates will be posted on this page with a revised effective date.

Contact

If you have questions about this privacy policy, you may contact the developer through the contact information provided in the Chrome Web Store listing.
